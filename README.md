# Stock Opname App (Stock Aggregator)

Aplikasi manajemen stok barang (Stock Opname) yang dibangun menggunakan Node.js, TypeScript, dan React (Monorepo).

## 🏗️ Struktur Proyek

*   `artifacts/stock-opname` : Aplikasi utama (Frontend + Backend).
*   `artifacts/api-server` : Server API.
*   `artifacts/mockup-sandbox` : Area pengembangan UI.
*   `lib/` : Library internal yang digunakan bersama (API client, DB schema, dll).
*   `scripts/` : Skrip pendukung.
